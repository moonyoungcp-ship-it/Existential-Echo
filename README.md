# Existential-Echo

**일상의 문학** — 평범한 하루를 한국 현대 문학으로 변환하는 앱

한강, 김애란, 편혜영의 문체에서 영감을 받아, 일상의 일기 형식 글을 서정적이고 실존적인 현대 한국 산문으로 변환합니다.

## 실행 방법

```bash
pip install -r artifacts/literary-transformer/requirements.txt
streamlit run artifacts/literary-transformer/app.py
```

## Streamlit Cloud 배포

- Main file path: `artifacts/literary-transformer/app.py`
- Branch: `main`
